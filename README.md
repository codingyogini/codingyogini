# Hi, I'm Irene

I build AI products, and I like to understand them down to the code.
I started as an engineer, moved into ML research (MSc, McGill), and now lead AI product work in Montreal.

Most of what I build lives inside companies. This is where I publish side projects.

## Current personal projects

- **[ProductizeAI-Architect](https://github.com/codingyogini/productizeai-architect)**: a Claude skill that redesigns a product or workflow around AI. It decides what stays deterministic, how much autonomy each step gets, and how to test the result before scaling.
- **[Heard](https://github.com/codingyogini/heard-product-feedback)**: turns public product feedback into a Build / Watch / Ignore report. The model proposes themes, code checks every quote and count, and a product manager makes the final call.

When AI actually beats a rule or a process fix. How much autonomy an agent should get. How to prove an AI feature works before it ships.
